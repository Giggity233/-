# 更新日志

## 2026-11-24 · v1.15.1

- 账号管理中心新增“只看有机器人账号的店铺”筛选，页面、异步 JSON 列表和分页均会保留该条件。
- AI 知识库新增无鉴权读取接口 `GET/POST /api/v1/ai/order-urging-scripts/store/`：传入店铺编号即可获取店铺最终生效的待支付、未下单催付话术，并兼容客户级继承与上级屏蔽规则。

## 2026-10-30 · v1.15.0

- 售后处理中控新增“微信群待发送”：系统自动创建一个共享待发送队列，提供追加信息、读取全部信息、回传已发送并清空队列三类接口；多条信息按换行保存和读取。
- 登记表格新增“远程登记”：内部专员客服与管理员可登记机器号、远程码、远程密码，系统自动记录当前登记人；支持修改、删除和分页查看，客户账号无权访问。

## 2026-10-16 · v1.14.0

- 数据中控新增客户账号管理：管理员可为每个客户手工创建唯一登录账号、启停账号和重置密码；客户登录后仅可查看其名下店铺数据和店铺账号信息，并可自行修改密码。
- 客户编辑页可配置客户账号可见的店铺数据字段，并分别授予本客户店铺知识库、商品知识库的只读权限；售后策略配置对客户账号仅开放本客户店铺的只读内容。
- 售后处理中控新增发票中心：支持 PDF 补传、失败记录恢复未处理、按日期/状态/客户/店铺/订单号的 JSON 筛选分页，并提供发票写入、按日期拉取 100 条待处理记录、批量回传结果三类接口。
- 售后处理中控新增留言管理：支持客户与专员登记任务、按客户共享快捷话术、删除任务、专员更新处理状态，以及待处理读取与批量状态回传接口。客户的数据范围严格限制为自身店铺。

## 2026-10-08 · v1.13.15

- 修复 Windows 服务包漏收集 `waitress` 导致启动后报 `ModuleNotFoundError: No module named 'waitress'` 的问题；构建脚本现在显式收集该生产 WSGI 服务依赖。

## 2026-10-08 · v1.13.14

- 客户素材知识库详情新增“继承该素材的商品”列表：同时展示手动标注和标题、SKU、属性自动命中的商品，并可直接查看商品知识库。
- 可在素材详情对单个商品执行“屏蔽整个素材”或恢复继承；整项屏蔽会同步排除该素材的提示词、问答对、关键词以及后续新增素材内容，不影响其他素材或商品自身知识。
- 客户素材知识库列表新增按客户筛选和素材删除；删除素材会一并删除其知识内容、屏蔽记录，并取消商品上的手动素材标注。列表继续支持分页及异步加载。

## 2026-10-08 · v1.13.13

- 商品自动命中客户素材后，现在会同时继承该素材的关键词；商品知识库展示、汇总接口和商品级逐条屏蔽均已同步支持。
- 新增无鉴权关键词匹配接口 `GET/POST /api/v1/ai/knowledge/keywords/match/`：传一句文字和商品 ID，命中完全一样/包含规则时返回对应回答，未命中返回“无匹配”。

## 2026-10-08 · v1.13.12

- 所有业务页面中的密码输入框与账号密码列表统一改为明文显示；账号密码登记新增按店铺名模糊筛选及下拉建议。
- 登记表格新增独立的“图片对应文字”页面：图片按知识库样式与右侧文字并列显示，登录用户可修改文字或删除记录；新增无鉴权写入接口 `POST /api/v1/image-text-registrations/create/`。

## 2026-10-07 · v1.13.11

- 客户素材知识库新增商品自动继承：商品标题、SKU 或属性区分大小写地包含客户素材名称时，商品知识库和汇总接口自动继承该素材的提示词、问答对；可同时命中多个素材。
- 自动继承实时依据最新商品资料计算，资料不再匹配时即取消；每条自动继承内容仍可在对应商品下单独屏蔽。原有手动素材标注及其关键词继承不受影响。

## 2026-10-06 · v1.13.10

- 账号密码登记列表改为与数据中心一致的异步 JSON 数据源：首次打开、负责人/客户筛选和分页均由前端请求 `GET /api/v1/account-password-registrations/` 后渲染，避免大量登记记录导致页面卡顿；新增、修改、删除后会自动请求并刷新最新列表。

## 2026-10-06 · v1.13.9

- 账号密码登记改为单一账号类型字段：可选专员账号（默认）或机器人账号；新增可共享的“平台”字段，默认拼多多，支持手工新增与复用全部历史平台值。
- 登记记录新增操作人，页面新增与修改时自动显示当前登录账号的负责人姓名；全部登录账号可共同查看、修改、删除记录，修改后操作人同步更新。

## 2026-10-06 · v1.13.8

- AI 知识库菜单新增“售后策略配置”：仅可选择已登记 Cookie 的店铺，新增时先选择客户，再展示该客户下可配置店铺；支持修改、删除与按客户/店铺筛选。
- 策略支持补偿比例、补偿金额两种补偿类型，支持一至三阶补偿、上下限和质保时间；协商方式支持补偿、补发及新增的退款，数值为 0 时不执行。
- 新增无鉴权读取接口 `GET /api/v1/after-sales-strategies/?shopid={店铺编号}`，按店铺编号返回售后策略 JSON；编号跨平台重复时补传 `platform`。

## 2026-10-06 · v1.13.7

- 新增独立的“登记表格 → 账号密码登记”菜单与数据表：店铺名、账号名、登录账号/密码、手机号、负责人 1/2、客户、专员账号、机器人账号、备注均可选填，并按添加时间倒序展示。
- 负责人和客户支持可模糊搜索的下拉建议及手动输入，可按负责人、客户筛选；新增无鉴权写入接口 `POST /api/v1/account-password-registrations/create/`。
- 登记表不与现有店铺、客户、用户或账号表建立任何关系，仅用于独立记录。
